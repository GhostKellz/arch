# CKTech Hudu

Hudu at `hudu.cktechx.com` is the client-confidential system of record.

Use Hudu for client companies, assets, passwords, procedures, M365/infra/security docs, and client-specific runbooks.

Prefer native Hudu MCP with Streamable HTTP and OAuth. Avoid API-key fallback unless explicitly approved.

Do not copy Hudu client specifics into `~/brain/wiki/`. Generalize only patterns, removing client names, hostnames, IPs, tenant IDs, diagrams, and secrets.

Ask before write/update actions unless the user clearly requested the update.
